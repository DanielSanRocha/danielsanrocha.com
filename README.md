## Setup

You need to have 'nvm' installed in your machine. Install, using 'nvm', version v18.20.0 of node with the command:

```bash
nvm install 18.20.0
```

## Deploying to Production

You can generate static files for deploying in any server with:

``` bash
make build
```

The generated files will be ready in the 'dist' folder.

## Developing

Start a local development server with the command:

``` bash
make dev
```

the server will be ready at 'localhost:3000'.
